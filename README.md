# DUNBAR Font

DUNBAR（目黒）のオリジナル書体。見出し・ロゴ用。

| ファイル | ウェイト |
| --- | --- |
| `DUNBAR-Regular.ttf` | Regular (400) |
| `DUNBAR-Bold.ttf` | Bold (700) |

## Web で使う

```css
@font-face {
  font-family: "DUNBAR";
  src: url("DUNBAR-Regular.ttf") format("truetype");
  font-weight: 400;
}
@font-face {
  font-family: "DUNBAR";
  src: url("DUNBAR-Bold.ttf") format("truetype");
  font-weight: 700;
}
```
